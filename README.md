# LLM SQL Project

## Overview

The **LLM SQL Project** simulates an Excel or Google Sheets-like application where users can interact with data stored in an SQLite database using natural language. The application dynamically loads CSV data into SQLite, creates tables from the CSV structure, and integrates OpenAI's GPT-3 (or similar models) to generate SQL queries from user input.

Users can chat with the system in plain language to perform operations like querying data, generating reports, and more. The system leverages a language model (LLM) to convert these natural language queries into SQL statements, which are then executed against the database.

## Features

1. **CSV to SQLite**: Automatically load CSV data into SQLite.
2. **Dynamic Table Creation**: Create SQL tables based on CSV schema.
3. **Schema Conflict Resolution**: Handle cases where the table schema already exists with options to overwrite, rename, or skip.
4. **Interactive CLI**: Chat with the system to run SQL queries and get results using a simple command-line interface.
5. **LLM Integration**: Use OpenAI's language model to convert natural language queries into SQL queries and execute them on the database.

## Detailed Breakdown

### Step 1: Load CSV Files into SQLite

The system allows you to load CSV files into SQLite databases. It automatically maps the CSV data into tables and infers column names and data types.

Example CSV data:

```csv
product_id,product_name,category,price
1,Apple,Fruit,1.2
2,Banana,Fruit,0.5
3,Carrot,Vegetable,0.8
4,Tomato,Vegetable,1.0
5,Chicken,Meat,5.0
```

### Step 2: Automatically Create SQL Tables from CSV

The system dynamically creates SQL tables based on the CSV structure. It inspects the column names and data types from the CSV to build the necessary SQL table definitions.

### Step 3: Handle Schema Conflicts

If a table with the same name already exists, the system prompts the user to choose whether to overwrite the existing table, rename it, or skip the operation. Errors are logged to an `error_log.txt` file.

### Step 4: Chatbot Interface for Running Queries

Users can interact with the system through a simple command-line interface (CLI). The system accepts natural language queries, such as:

- "Show me the top 5 products by total revenue."
- "What is the average price of all vegetables?"

The system converts these queries into SQL using the OpenAI language model and returns the query results.

### Step 5: Integration with OpenAI's Language Model

OpenAI's language model is used to translate natural language queries into SQL queries. The application passes the user input along with database schema details to the AI, which generates the corresponding SQL query. The system then executes the query on the SQLite database and displays the results.

## Example Query and SQL Translation

**User Query**: "Show me the top 5 products by total revenue this month."

The language model will generate the following SQL query:

```sql
SELECT p.product_name, SUM(s.revenue) as total_revenue
FROM sales s
JOIN products p ON s.product_id = p.product_id
WHERE strftime('%Y-%m', s.sale_date) = strftime('%Y-%m', 'now')
GROUP BY p.product_name
ORDER BY total_revenue DESC
LIMIT 5;
```

The system will then execute this query on the SQLite database and display the results.
