# LLM SQL Project

## Overview
This project simulates an Excel or Google Sheets-like application where the user interacts with the system using natural language queries. The application loads CSV data into an SQLite database, dynamically creates tables, and integrates OpenAI's language model to generate SQL queries based on user input.
